Welcome to my **Machine Learning and Data Science Internship** project repository. This repository contains my practical work, Jupyter notebooks, model evaluations, and visualizations developed as part of the Datheon internship.

The projects focus on applying machine learning and data science techniques to real-world classification, regression, customer analytics, and natural language processing problems.

## 📂 Projects

### Task 1: Iris Classification

**Focus:** Supervised machine learning classification.

- Explore and preprocess the Iris dataset.
- Apply feature scaling and train/test splitting.
- Train Logistic Regression and Decision Tree models.
- Evaluate performance using accuracy, precision, recall, F1-score, and a confusion matrix.

**Folder:** `task1_iris_classification/`

### Task 2: California Housing Price Prediction

**Focus:** Regression and regularization.

- Predict median house values using the California Housing dataset.
- Compare Ordinary Least Squares (OLS), Ridge, and Lasso regression.
- Explore feature engineering, scaling, and model tuning.
- Evaluate models using RMSE, MAE, and R².

**Folder:** `Task_2_California_Housing/`

### Task 3: Predictive Customer Churn Classifier

**Focus:** Classification and imbalanced data.

- Predict customer churn from telecom subscription records.
- Preprocess categorical features using OneHotEncoder.
- Explore class imbalance handling with SMOTE or class weighting.
- Compare Random Forest and XGBoost classifiers.
- Evaluate ROC-AUC, classification metrics, and feature importance.

**Folder:** `Task_3_Customer_Churn_Classification/`

### Task 4: NLP Sentiment Classification Using TF-IDF

**Focus:** Natural Language Processing (NLP).

- Clean and preprocess customer reviews.
- Transform text into TF-IDF feature vectors.
- Train Multinomial Naive Bayes and Logistic Regression models.
- Evaluate sentiment classification performance.
- Implement a `predict_sentiment()` function for custom text input.

**Folder:** `Task_4_NLP_Sentiment_Classification/`
