# Task 1: Iris Flower Classification

## Datheon Machine Learning & Data Science Internship

This project implements supervised machine learning classification models on the Iris dataset as part of Task 1 of the Datheon Machine Learning & Data Science Internship.

## Project Overview

The objective of this project is to classify Iris flowers into three species using their sepal and petal measurements. Two machine learning algorithms are implemented and evaluated: Logistic Regression and Decision Tree Classifier.

## Dataset

- **Dataset:** Iris Flower Dataset
- **Source:** Seaborn built-in Iris dataset
- **Features:** Sepal length, sepal width, petal length, and petal width
- **Target:** Setosa, Versicolor, and Virginica
- **Train-test split:** 80% training and 20% testing

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## Methodology

1. Load and explore the Iris dataset.
2. Perform exploratory data analysis and visualize feature relationships.
3. Split the dataset into training and testing sets using an 80:20 ratio.
4. Apply feature scaling using `StandardScaler`.
5. Train Logistic Regression and Decision Tree classification models.
6. Evaluate model performance using accuracy, precision, recall, and F1-score.
7. Visualize the classification results using confusion matrices and other relevant plots.
